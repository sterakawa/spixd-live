# SPIXD LIVE

SPIXDの管理画面（ENTRY LIST）の撮影ログを解析し、イベント現場の「いま」を可視化する実験プロジェクトです。

## Prototype 0.1

まずはSPIXD本体を変更せず、保存した `ENTRY LIST.html` をブラウザで読み込んで解析します。

表示するもの:
- 累計撮影数
- 直近5分 / 10分 / 30分の撮影数
- 直近30分の1時間換算ペース
- 平均撮影間隔
- 最終撮影時刻
- 5分単位の推移
- LIVE STATUS（ルールベース）

## 使い方

1. SPIXD管理画面の ENTRY LIST をHTMLとして保存
2. `index.html` をブラウザで開く
3. 保存したHTMLを選択
4. SPIXD LIVEがログを解析して表示

現段階では外部送信・AI API呼び出しは行いません。撮影ログの解析ロジックと、現場で役に立つ表示項目を先に検証します。
